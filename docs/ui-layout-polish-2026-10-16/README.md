# Web 布局与图标打磨 · 2026-10-16

基于 `a6b6995`（新版熊猫已合入 main）修复用户截图中的衣橱、排行榜和学习路径问题。本目录截图来自本地**生产构建**，预览地址为 `http://127.0.0.1:3053/`；本轮改动尚未发布到 CloudFront。

## 修改与原因

- **衣橱**：移除挤占商品空间的右栏。商品卡最小宽度 128px；名称可换行，价格与稀有度分层。预览与商品双列、预览 sticky 共用 760px 容器断点，单列时不吸附。点击商品只预览，明确点击行动按钮才解锁或装备，移开鼠标不重置预览。
- **共用框架**：768px 起显示窄导航，1024px 展开导航，1280px 才显示右栏。右栏出现时隐藏页面内的同类状态栏；排行榜不再重复显示解锁推广。修复宝石脉冲动画结束后仍撑宽右栏的透明元素。
- **图标与任务**：商店使用购物袋图标，与宝石余额区分；连胜改为可辨认的火焰；统一导航图标与激活态，简化每日任务奖励区。小熊猫装饰改用实际 Mascot，缩略分类图标保留统一线条。
- **学习路径**：节点、标题和单元分隔采用正常文档流，连接线根据实际行高绘制。标题完整换行，单元挑战不再压住下一单元。听读与故事入口合并为简洁按钮。
- **个人页**：小屏欢迎区采用两列分行，顶栏状态单独换行，目标圆环支持暗色背景，避免欢迎语被挤成竖排。每日任务在无右栏的桌面个人页也可访问。
- **本地开发**：仅生产模式注册 Service Worker，避免开发时缓存旧的非哈希客户端模块。生产注册逻辑保留。

## 核验证据

原线上 1440px 衣橱的商品卡约 61px，12 个名称全部截断；右栏产生横向滚动。排行榜有两组红心/连胜状态和重复解锁提示，详见 [修改前测量](before.json)。

最终生产构建共 41 组页面/尺寸检查通过，控制台未记录错误。核验结果见 [响应式测量](production-matrix.json)、[其余共用页面测量](common-pages.json) 和 [交互结果](production-interactions.json)。断言脚本为 [`scripts/checks/web-layout.js`](../../scripts/checks/web-layout.js)，通过浏览器工具在已渲染页面只读执行，检查页面/侧栏横向溢出、可见状态重复、商品宽度与文字裁剪、预览重叠、路径标签间距。

验证尺寸为 320、375、390、768、1024、1280、1440px；实际滚动与浅/深色显示另由截图核验。这里是浏览器视口测试，未进行儿童或物理设备验收；未用真实余额进行解锁消费。

其他检查：`npm run type-check`、216 项 core 测试、Next.js 生产构建、`git diff --check`。本轮不修改题库、答案、存档或经济计算。
