# 全站 Web 体验复查 · 2026-10-16

在 PR #19 的布局修复之上，检查全部页面类型和实际操作状态。检查环境是独立 localhost 测试存档与 Next.js 生产构建，未修改用户线上进度，未合并或发布本轮修改。

## 发现并修复

| 等级 | 复现与影响 | 修复 / 证据 |
| --- | --- | --- |
| P1 | 首次选年级的「继续」被底部主导航遮挡，点击实际进入「我的」 | 复用 #13 的引导层级、全宽按钮和安全区修复，首访隐藏底部导航，保留 #19 导航设计。见 [修改前](onboarding-before.jpg) |
| P1 | 英文故事答案 `True`，选择「对」被判正确，但「错」却高亮为正确 | 组件移除独立且大小写不一致的真值表，直接复用判分逻辑。24 个实际组件渲染回归用例；[原错误反馈](story-feedback-before.jpg) |
| P1 | `thirty-first` 缺少连字符键，且输入截断为 `thirtyfirs`，无法答对 | 候选键保留连字符；输入长度覆盖该题答案；长文本换行；英文提示改成「字母」。扫描发现课程和故事中共 20 道文字答案原始长度超过 10 字符；不能把这 20 道都解释为语义错误。[修改前](long-answer-before.jpg) |
| P1 | 不存在的第 999 单元可以进入跳级；加载部分前置题目失败时仍能组卷并解锁全部前置课 | 校验目标单元存在，前置题库完整加载才允许开始；无效链接和缺失资源显示可恢复的错误。`jump-loading.ts` 覆盖不存在、缺失、空题库等条件 |
| P1 | 听读把播放失败、静音、中断等 Promise 返回当作播放完成；跟读检查的是旧 React 状态，权限拒绝后也可能发完成奖励 | 使用明确的播放结果；逐句自然结束、逐句成功取得录音才记录完成。录音开始直接返回成功与否，取消待授权请求时会释放迟到的媒体流。受控回归验证，无真实麦克风采集 |
| P2 | 7 页知识手册的圆点撑出屏幕，320px 下 `scrollWidth=328 > clientWidth=305` | 进度指示可收缩、关闭按钮 44px，手册归入沉浸式路由，不再出现主导航。[修改前](guide-before.jpg) |
| P2 | 手册点下一步后仍停在底部，新标题 `top=-289.5px`；长公式撑宽整页 | 翻页完成后聚焦新标题并回顶部；公式在自身容器内滚动，题干保留可收缩宽度 |
| P2 | 320px 配对题的字母/数字与重复快捷键挤占词语空间，汉字变成竖排 | 窄屏隐藏额外键位编号，调整卡片留白和文本宽度，补充操作提示。完成四对后实际自动判对 |
| P1 | 桌面打开换书后缩窄窗口，弹窗尺寸变为 0×0，但 body 仍为 overflow:hidden | 共用弹窗通过 Portal 挂到 body，脱离隐藏/变换祖先；[失败断言](chooser-before.json) |
| P2 | 多个弹窗的 `aria-labelledby` 指向不存在的节点；报错抽屉无焦点管理和 Esc 返回，低高度屏幕可能裁掉操作 | 统一明确名称、限制高度并允许内部滚动；报错使用共用弹窗，焦点进入、Esc 关闭后归还原按钮，弹窗内键盘不触发背后的答题快捷键 |
| P2 | 学科卡的白字对鲜艳背景难读，多个关键辅助按钮仅 32–40px | 复用 #13 的深色学科卡文字方案；扩大退出、设置、音频、翻页、排序词块、备份与时间设置操作，补充选中状态 |
| P2 | 英文/长标题截断，空错题页鼓励「保持零错误」，默认 404 缺少友好返回 | 内页标题换行；空错题页鼓励练习；新增中文 404 和返回学习入口。阅读器提供音效开关，播放受阻后可直接恢复声音 |

## 自动与浏览器核验

- `npm test`：216 项 core 测试通过；`npm run type-check` 通过。
- 新增 `npm run check:web-experience`：实际判断题组件渲染、文字键盘、跳级数据装载、听读完成条件、录音生命周期。测试曾在原错误实现上失败后再通过。
- 原有讲解播放器、TTS 旧资源兼容、Service Worker 回归通过。
- Next.js 生产构建成功；全量导出页面引用检查见 [navigation.json](navigation.json)。检查覆盖导出 HTML 的本地链接与图片，不代表人工逐题审核内容。
- 181 组页面几何与显示检查全部通过（125 组首访/常规页面 + 48 组浅色复验 + 8 组已解锁/零红心状态）。这只表示显示断言通过，零红心业务阻碍仍在。页面几何、标题、图片、沉浸导航和触控目标的只读检查：`scripts/checks/web-experience.js`；[多尺寸证据](page-matrix.json)。
- [真实交互记录](interactions.json)：静音播放前后均为 0 XP，完整听读后为 5 XP；测试衣橱从 1120 扣除皇冠 250，并收到成就奖励 20，余额 890、已装备；时间上限刷新保留，首页回到当前教材；换书跨屏宽后可关闭，body 滚动恢复。
- 浏览器测量使用 320 / 390 / 768 / 1024 / 1440px。真实设备安全区、软键盘、屏幕阅读器朗读和儿童理解度不能用视口模拟代替。
- `.github/workflows/web-experience.yml` 将类型、core、新增体验回归和音频/离线回归纳入 PR 检查；结果以 GitHub 当前提交为准。

## 尚未解决的全站阻碍

**不能据此宣称全站已经可靠或达到多邻国水平。** 当前 main 和线上仍未包含 PR #13 的以下修复：

1. 旧错题使用旧题面快照，遇到已经修订的答案时可能始终判错；题库更新后恢复仍可能沿用旧判分。
2. 排序/部分配对草稿刷新丢失；退出的破坏性提示与课前强制多页听讲、冗长结算仍影响流畅度。
3. 少量到期错题不满足回心门槛、无到期题缺少额外巩固，可能无法从断心流程回到原课。
4. 单题课的星级/掌握表述，以及已知题目和音频内容纠错需要 #13 的内容和资源一起发布。

#13 在本轮读取时仍为 OPEN DRAFT（`4c0cb55`），已有 `Web UX regressions` 检查通过。本轮只复用其中边界清晰的引导和可读性改动，未将其题库、存档、奖励与资源变更重复搬入 #19。两个分支共享的 UI 文件后续需要解决合并冲突。

另有内容问题需教师/编辑验收：示例配对题说「首字母与单词」但实际配的是英文与中文；故事配图与正文角色可能不一致。这里不靠猜测改题或重生成媒体。

没有执行生产部署，没有恢复已暂停的自动追踪任务。所有截图来自本地构建；浏览器行为、受控异常和未实测项目分别标明。
