# 全站视觉与交互打磨 · 2026-10-16

本轮继续在 PR #19 上逐页检查，使用独立 localhost 存档与真实浏览器。所有截图来自本地生产构建，没有部署到线上。覆盖页面类型与代表状态，不把自动检查解释为所有题目、所有可能状态或真机/儿童验收。

## 本轮修复

- 深浅色的文字前景与鲜艳背景色分离；辅助文字、选中标签、按钮文案与填空提示可读。深色答题卡的基础样式不再覆盖选中/正确/错误状态。
- 界面主题此前只改变部分背景，按钮颜色仍固定；现真正应用主题强调色，并为普通与悬停按钮选择可读前景。10 套主题、两种模式的标签和按钮对比度纳入回归。宝石保留固定蓝色，避免跟随主题变成另一种资源。
- 衣橱商品名称、价格、稀有度与预览分开；主题预览遵循当前外观模式；余额不足显示明确差额和学习入口。
- 个人页先显示学习概况，取消占屏的固定页头；快捷入口、护盾与外观成对排列，周报单独占行，避免短入口被拉成大片空白。成就默认展示 4 项，可展开全部 16 项，文字不截断、分享按钮可触达。
- 教材学科卡的代表字在深色模式下原本落在深色圆底上；保留亮色徽章以保证辨识。桌面标题区按原设计透明，不再被全局深色背景规则覆盖成方块。
- 听读和故事列表保留完整标题/作者；阅读器内页标题放大，正文行宽允许收缩，图片页码使用更清楚的底色。声音开关和单句按钮有明确的状态/编号。
- 知识手册压缩装饰图标与留白，翻页入口持续可达；分数等行内公式消除多余纵向滚动条。路径单元标题允许换行，跳级提示文字可读。
- 弹窗隔离背景交互，Tab 从对话框容器正确进入第一个操作，Esc 归还焦点；连胜日历格子随窄屏缩小，长提示不再用省略号隐藏。
- 移除续学卡固定显示 60% 的装饰进度，保留真实作答数量；配对操作提示改为通用于不同学科的「找到对应的一对」。
- 录音审查新增两个已复现的竞态：旧权限请求迟到拒绝会停止新录音；旧跟读循环结束时也会停止新录音。分别隔离请求代次与会话回调，两个回归先失败后通过。故事播放停止/重试也隔离旧回调，播放失败给出可恢复提示；录音回放复用单例播放器，避免与原音叠播。

## 检查方式与范围

以 [page-matrix.json](page-matrix.json) 为实际尺寸、模式、路由及检查结果的记录。页面图像、文字层级、留白与状态反馈做目视核对；`scripts/checks/web-readability.js` 对实际渲染的纯色文本计算对比度，常规文字至少 4.5:1、大字至少 3:1。渐变、图片内文字、淡入过程与禁用控件另行目视检查，不将跳过项算为对比度通过。

覆盖：首访、年级教材、路径、手册/空手册、课前讲解、数字/文字填空、排序、配对、判断、选择、错题本/空队列、正常/异常跳级、听读列表/阅读器、故事列表/阅读器、个人页、排行榜、衣橱、404。长标题、长正文、实际解锁、已解锁榜单、错误反馈、低高度弹窗、键盘切换、折叠展开、刷新保持另有状态核验。

最终矩阵：**24 类页面 × 390×844 / 1440×900 × 浅色 / 深色，共 96 组**。2,515 处纯色文本取样，记录的对比度、横向溢出、标题裁切、缺图、沉浸导航断言均无失败；取样包括重复导航与页外正文，不是 2,515 条独立设计。另有 [17 组状态记录](state-matrix.json)，覆盖 320×568、1024×768、主题装备、已解锁榜单、待复习、余额不足和播放失败。

最后一轮还发现课前静音/播放失败时的「阅读后继续／重新播放」只有 20px 高，已扩展到 44px，并在四个模式组合单独复验；排行榜 320px 的段位行缩小间距和徽章，铜牌名次使用深色前景。

验证：216 项 core 测试、类型检查、6 组 Web 体验回归、讲解播放器、TTS 旧资源与 Service Worker 回归通过。Next.js 生产构建通过，全量 HTML 引用检查：3,898 个文件、5,142 个引用、0 缺失（[记录](navigation.json)）。
