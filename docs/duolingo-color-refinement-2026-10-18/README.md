## 为什么上一版发灰

上一版 themeAccentColors 的 action() 为白色按钮文字达到特定对比度，循环降低所有 RGB 通道：#58CC02 被压成 #46A302，蓝色也被压暗。并且 `.text-primary`、`.text-secondary`、`.text-gold` 被当作可读正文处理，单色 SVG 继承后变成深绿、深蓝或棕色。颜色名正确不代表页面最终显示正确。

这轮保留按钮色面的原始亮度与明确的底边色；小字说明仍有独立的深色文字令牌。白字亮色按钮按官方 Web 的视觉约定实现，不宣称其白字满足 WCAG AA 对比度。

## 按钮与图标

实测课程 Check：50px 高、16px 圆角、17px/700、白字，伪元素色面 #58CC02，底边阴影 0 4px 0 #58A700。普通选项文字19px/500，选中色面 #DDF4FF、文字 #1899D6、底边2px #84D8FF。

- 统一操作标签17px/700和选项19px/500；硬底边按压缩回，禁用态不保留立体阴影。
- 重画首页、盾牌、错题本、商店、个人和宝石 SVG：更大的轮廓、明确的平面色块，减少细碎装饰。保留自己的熊猫品牌。
- 奖励与工具图标不再继承为正文调暗的颜色。
- 排行榜待解锁插画改用蓝、黄、紫三枚徽章，替换旧版灰棕色组合。
- 原文证据弹窗扩为阅读宽度，返回按钮固定在滚动区域顶部。
