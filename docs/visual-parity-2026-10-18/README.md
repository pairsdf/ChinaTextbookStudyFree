## 按钮、字体、图标

- 共用按钮高50px、圆角16px；主操作4px底边，描边操作2px底边；桌面练习主辅动作宽150px。
- 补足Nunito 400/500字重，正文17px/500、中文主动作19px/700、桌面题干28px。保留中文系统字体回退，没有复制专有Duo Sans。
- 浅色主操作用白字，深色用按填充亮度选择的前景。动作填充与品牌装饰色分离，19px/700文字至少3:1对比度，现有常规标签与填充前景4.5:1检查保留。
- 重画店面、熊猫头像、联赛盾牌、立面宝石；功能控件保留一致的单色圆头线条。移除讲解按钮的SVG发光描边，保留小型真实音频进度条与禁用语义。
