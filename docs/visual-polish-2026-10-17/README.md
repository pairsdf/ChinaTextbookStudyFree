## 改动

- 白色默认底面与中性边框，绿色主操作、蓝色选中态、独立错误/成功反馈。保留所有已有换肤及免费深色模式。
- 主导航、教材、状态、任务、成长入口使用同组双色实心自绘SVG。功能图标统一圆头笔画；教材图标在年级页和换书入口复用。
- 按钮高50px、圆角16px、硬底4px；小控件至少44px；统一按压、禁用、焦点与减少动态效果。
- 共用题干/朗读入口；修复含部分音频选项时的宽度不齐。手机题干从652.25px提前到110px；检查按钮由998.75px提前到778px。
- 课程/复习采用可滚动题区与持续可见操作栏，换题重置题区滚动。讲解手册移到题目之后，手机练习移除大块吉祥物占位。
- 年级选择、教材、学习路径、示范单元、错题本、衣橱、个人页和阅读页统一间距与字体；修正衣橱预览裁切。375×667比较题所有选项在检查栏之上。

## 参照与限制

参照 [Duolingo公开Web](https://www.duolingo.com/) 与 [官方设计文章](https://blog.duolingo.com/hub/design/)，公开引导继续按钮观测为50px高/16px圆角/4px底边。没有把登录后的所有界面或专有字体宣称为已复刻；本项目使用自绘SVG、Nunito及中文系统字体。

浏览器尺寸模拟尚未代替iOS/安卓真机与真实小学生试用。结构与自动测试不能证明全题库教学质量，也不能证明视觉审美100%一致。前一轮学习质量验收见 [对应记录](../learning-quality-2026-10-17/README.md)。
